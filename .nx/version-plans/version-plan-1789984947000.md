Reject the Wallet Standard promise with `WalletStandardError(WALLET_STANDARD_ERROR__USER__REQUEST_REJECTED)` when the user closes the sign modal, so dApps can detect a user rejection on `solana:signTransaction`, `solana:signAndSendTransaction` and `solana:signMessage`.
