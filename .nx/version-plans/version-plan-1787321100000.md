Move the EVM get-address model and the EIP-1193 / EIP-6963 contracts from core to the EVM provider package, and stop re-exporting the EIP contracts from `@ledgerhq/ledger-wallet-provider`. Import them from `@ledgerhq/ledger-wallet-provider-evm` instead.

The `method` field of `SignTransactionParams` and `SignRawTransactionParams` is now typed as `string` in core, since the `RpcMethods` union it used to reference is owned by the EVM provider.
