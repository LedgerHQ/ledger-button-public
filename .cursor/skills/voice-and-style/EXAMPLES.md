# Voice and Style: Do / Don't Examples

Use these when applying the voice-and-style skill. Replace or add rows to match your company style. Examples below follow **American English (Chicago Manual of Style)** where relevant; see [VOCABULARY.md](VOCABULARY.md) and [REFERENCE.md](REFERENCE.md).

**Chosen tone for this project:** Semi-formal; avoid contractions in body text; use personal pronouns only when they add clarity (e.g. "You can find it in the dashboard"). Humour only in subtitles or section headings—**do not** use humour in steps, reference, or technical instructions.

---

## Tone and register

| Do | Don't |
|----|--------|
| Semi-formal, clear phrasing. | Overly casual ("Hey, just hit the button") or stiff ("One must proceed to…"). |
| We recommend that you enable two-factor authentication. | You might want to consider enabling 2FA. (Clear recommendation; avoid vague hedging.) |
| Do not use humour in step-by-step or reference content. | Do not add jokes, puns, or wit in technical instructions or reference. |
| A light touch in a subtitle or section heading is acceptable (e.g. "When things go wrong"). | Do not use humour in body text, steps, or code comments. |

---

## Contractions and personal pronouns

| Do | Don't |
|----|--------|
| Do not skip this step. / It is required for the next phase. | Don't skip this step. / It's required. (Avoid unnecessary contractions in body text.) |
| Click **Save** to store your changes. (Imperative; "you" implied.) | You need to click the save button. (Unnecessary "you" when the imperative is clearer.) |
| Ensure the account is active before continuing. | Ensure your account is active. (Drop "your" when "the" or no pronoun is enough.) |
| If the signer is not recognised, check the cable. | If your signer isn't recognised, check the cable. (Prefer full form "is not"; avoid "your" if not needed.) |
| You need a project ID. You can find it in the dashboard. | Users must have a project ID which can be found in the dashboard. (Use "you" when addressing the reader directly; avoid passive and "users".) |

**Note:** Use "you" when it adds clarity (e.g. "You can find it in the dashboard"). Omit pronouns when the imperative or a neutral subject is clearer (e.g. "Click **Save**", "The API returns a token").

## UI and actions

| Do | Don't |
|----|--------|
| Click **Save** to store your changes. | Hit the save button. |
| In **Settings** > **Account**, enter your email. | Go to settings and then account and type your email. |
| Select **Organise** to sort the list. | Select organize to sort the list. (Use European spelling and bold the UI label.) |

---

## Reader address

| Do | Don't |
|----|--------|
| You need a project ID. You can find it in the dashboard. | Users must have a project ID which can be found in the dashboard. |
| If you run into issues, see Troubleshooting. | In the event that issues are encountered, refer to Troubleshooting. |
| Ensure the account is active before continuing. | Insure your account is active. (Use "ensure" for making sure; "insure" for insurance; drop "your" when not needed.) |

---

## Technical phrasing

| Do | Don't |
|----|--------|
| The API returns a token. | A token is returned by the API. |
| The service recognises the certificate. | The service recognizes the certificate. (Use European spelling: recognise.) |

---

## American English (spelling and usage)

| Do | Don't |
|----|--------|
| The organization provides guidance on style. | The organisation provides guidance. |
| Use the center panel to configure options. | Use the centre panel. |
| Fewer than ten items; less time required. | Less than ten items (use "fewer" for countable nouns). |
| The report, which was updated in 2025, is available. | The report, that was updated in 2025, is available. (Use "which" for non-restrictive clauses.) |
| Behavior is consistent with the guidelines. | Behaviour is consistent to the guidelines. ("Different from" / "consistent with".) |

---

## Product and signer terminology

| Do | Don't |
|----|--------|
| Connect your Ledger signer to your computer. | Connect your Ledger device to your computer. |
| Use Ledger Wallet (the all-in-one crypto app) to manage your accounts. | Use Ledger Live (the companion app) to manage your accounts. |
| Ledger OS runs on your signer. | BOLOS runs on your device. |
| Classics and Original Ledger Nano signers use a smaller display. | The Ledger Nano range of devices launched before the touchscreen version… |

**Note:** Context matters. In developer docs, "device" remains in API names (e.g. Device Management Kit). In user-facing and Academy-style content, prefer "signer". See [VOCABULARY.md](VOCABULARY.md).
